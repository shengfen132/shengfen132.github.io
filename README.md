# 🎮 游戏中心 - 在线小游戏平台

欢迎来到在线小游戏平台！这是一个包含多个小游戏的网站。

## 🎯 可玩游戏

### 🐍 贪吃蛇（增强版）
经典贪吃蛇游戏的增强版，实现内容包括：

- 更友好的 UI（分数、状态、速度、排行榜）
- **关卡系统（新增！）**：
  - 7个难度递增的关卡：初级、入门、进阶、高手、专家、大师、传奇
  - 随着关卡提升，游戏速度自动加快（每关提升约11%）
  - 道具出现概率随关卡提升而增加（15%→30%）
  - 达到目标分数自动升级到下一关卡
  - 升级时播放特殊音效并显示关卡信息
- **道具系统**：
  - ⚡ 加速：移动速度提升50%
  - 🐢 减速：移动速度降低50%
  - 💎 双倍分：吃苹果得2分
  - 🛡️ 无敌：可穿墙，不会自撞
  - ✂️ 缩短：立即缩短蛇身一半
  - 吃苹果后有概率生成道具（概率随关卡提升）
  - 场上最多同时存在3个道具
  - 道具30秒后自动消失
- 声音效果（使用 Web Audio API）
- 排行榜（localStorage，本地保存前 10）
- 移动端支持：
  - 虚拟 D-pad（触屏按钮）
  - 倾斜控制（DeviceOrientation，含 iOS 权限请求）
  - 触觉反馈（vibrate）
- 游戏逻辑与渲染解耦：`game.js` 包含核心逻辑，可以在浏览器或 Node 测试中复用

### ⭕ 井字棋
经典井字棋游戏：
- 支持双人对战
- 简洁友好的界面
- 自动判断胜负和平局
- 实时显示当前玩家
- 高亮显示获胜连线

## 📁 文件结构

- `index.html` - 游戏中心主页（游戏选择菜单）
- `snake.html` - 贪吃蛇游戏页面（包含虚拟按键、排行榜、模态）
- `tictactoe.html` - 井字棋游戏页面
- `style.css` - 全局样式
- `game.js` - 贪吃蛇游戏逻辑
- `script.js` - 贪吃蛇前端渲染与交互（包含声音、leaderboard、移动端优化）
- `tests/game.test.js` - （单元测试，测试 game.js）

## 🚀 快速运行（本地预览）

1. 在项目根目录运行一个静态服务：
   ```bash
   python3 -m http.server 8000
   ```
2. 打开浏览器访问 `http://localhost:8000/index.html`
3. 从游戏中心选择你想玩的游戏

## 🧪 运行测试（Jest，针对贪吃蛇 game.js）

```bash
npm install  # 安装依赖
npm test     # 运行测试
```

## 📱 移动端支持

贪吃蛇游戏支持移动端：
- 倾斜控制（DeviceOrientation）在 iOS Safari 需要用户显式授权
- 虚拟方向键（D-pad）自动在触摸设备上显示
- 触觉反馈（振动）
- 某些浏览器在未由用户交互触发的情况下会阻止 WebAudio 播放
