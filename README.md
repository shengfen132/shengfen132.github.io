# 🎮 游戏中心 - 在线小游戏平台

欢迎来到在线小游戏平台！这是一个包含多个小游戏的网站。

## 🎯 可玩游戏

### 🐍 贪吃蛇（增强版）
经典贪吃蛇游戏的增强版，实现内容包括：

- 更友好的 UI（分数、状态、速度、排行榜）
- **关卡系统（新增！）**：
  - 7个难度递增的关卡：初级、入门、进阶、高手、专家、大师、传奇
  - 随着关卡提升，游戏速度自动加快（每关提升约11%）
  - 道具出现概率随关卡提升而增加（15%→30%）
  - 达到目标分数自动升级到下一关卡
  - 升级时播放特殊音效并显示关卡信息
- **道具系统**：
  - ⚡ 加速：移动速度提升50%
  - 🐢 减速：移动速度降低50%
  - 💎 双倍分：吃苹果得2分
  - 🛡️ 无敌：可穿墙，不会自撞
  - ✂️ 缩短：立即缩短蛇身一半
  - 吃苹果后有概率生成道具（概率随关卡提升）
  - 场上最多同时存在3个道具
  - 道具30秒后自动消失
- 声音效果（使用 Web Audio API）
- 排行榜（localStorage，本地保存前 10）
- 移动端支持：
  - 虚拟 D-pad（触屏按钮）
  - 倾斜控制（DeviceOrientation，含 iOS 权限请求）
  - 触觉反馈（vibrate）
- 游戏逻辑与渲染解耦：`game.js` 包含核心逻辑，可以在浏览器或 Node 测试中复用

### ⚫ 五子棋
经典五子棋（Gomoku）游戏：
- 15x15 棋盘
- 支持双人对战
- 简洁友好的界面
- 自动判断胜负和平局
- 实时显示当前玩家
- 高亮显示获胜连线

### 🎲 2048
经典数字合并益智游戏：
- 4x4 网格
- 使用方向键或触摸滑动控制
- 相同数字的方块会合并
- 支持移动端触摸操作
- 本地保存最高分
- 自动检测游戏结束

### 🃏 记忆翻牌
经典记忆力游戏：
- 8对卡牌（16张卡）
- 翻开卡牌找到所有配对
- 显示翻牌次数和用时
- 支持触摸操作
- 挑战你的记忆力

### 🎯 打砖块
经典打砖块（Breakout）游戏：
- 控制挡板击碎所有砖块
- 关卡系统，难度递增
- 支持键盘、鼠标和触摸控制
- 生命值系统
- 彩色砖块设计

### 🚀 太空射击
经典街机风格射击游戏：
- 控制飞船击败敌人
- 自动升级关卡
- 支持键盘和触摸控制
- 敌人难度逐渐增加
- 流畅的射击体验

## 📁 文件结构

- `index.html` - 游戏中心主页（游戏选择菜单）
- `snake.html` - 贪吃蛇游戏页面（包含虚拟按键、排行榜、模态）
- `tictactoe.html` - 五子棋游戏页面
- `2048.html` - 2048 游戏页面
- `memory.html` - 记忆翻牌游戏页面
- `breakout.html` - 打砖块游戏页面
- `spaceshooter.html` - 太空射击游戏页面
- `style.css` - 全局样式
- `game.js` - 贪吃蛇游戏逻辑
- `script.js` - 贪吃蛇前端渲染与交互（包含声音、leaderboard、移动端优化）
- `tests/game.test.js` - （单元测试，测试 game.js）

## 🚀 快速运行（本地预览）

1. 在项目根目录运行一个静态服务：
   ```bash
   python3 -m http.server 8000
   ```
2. 打开浏览器访问 `http://localhost:8000/index.html`
3. 从游戏中心选择你想玩的游戏

## 🧪 运行测试（Jest，针对贪吃蛇 game.js）

```bash
npm install  # 安装依赖
npm test     # 运行测试
```

## 📱 移动端支持

所有游戏均支持移动端：
- 贪吃蛇游戏支持倾斜控制（DeviceOrientation）和虚拟方向键

- 触觉反馈（振动）
