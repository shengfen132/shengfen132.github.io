# 贪吃蛇（增强版，Web - 含道具系统和关卡系统）

这是贪吃蛇游戏的增强版，实现内容包括：

- 更友好的 UI（分数、状态、速度、排行榜）
- **关卡系统（新增！）**：
  - 7个难度递增的关卡：初级、入门、进阶、高手、专家、大师、传奇
  - 随着关卡提升，游戏速度自动加快（每关提升约11%）
  - 道具出现概率随关卡提升而增加（15%→30%）
  - 达到目标分数自动升级到下一关卡
  - 升级时播放特殊音效并显示关卡信息
- **道具系统**：
  - ⚡ 加速：移动速度提升50%
  - 🐢 减速：移动速度降低50%
  - 💎 双倍分：吃苹果得2分
  - 🛡️ 无敌：可穿墙，不会自撞
  - ✂️ 缩短：立即缩短蛇身一半
  - 吃苹果后有概率生成道具（概率随关卡提升）
  - 场上最多同时存在3个道具
  - 道具30秒后自动消失
- 声音效果（使用 Web Audio API）
- 排行榜（localStorage，本地保存前 10）
- 移动端支持：
  - 虚拟 D-pad（触屏按钮）
  - 倾斜控制（DeviceOrientation，含 iOS 权限请求）
  - 触觉反馈（vibrate）
- 游戏逻辑与渲染解耦：`game.js` 包含核心逻辑，可以在浏览器或 Node 测试中复用

文件：
- `index.html` - 页面入口（包含虚拟按键、排行榜、模态）
- `style.css` - 样式
- `game.js` - 游戏逻辑（同之前版本）
- `script.js` - 前端渲染与交互（包含声音、leaderboard、移动端优化）
- `tests/game.test.js` - （保留你的单元测试，测试 game.js）

快速运行（本地预览）：
1. 在项目根目录运行一个静态服务（例如）：
   - Python3: `python -m http.server 8000`
   - 然后打开浏览器访问 `http://localhost:8000/index.html`

2. 本地测试（Jest，针对 game.js）：
   - 确保 Node.js 已安装
   - 安装依赖：`npm install`
   - 运行测试：`npm test`

移动端注意事项：
- 倾斜控制（DeviceOrientation）在 iOS Safari 需要用户显式授权。页面上会显示“启用倾斜（权限）”按钮（仅在需要时显示）。
- 如果你希望倾斜控制在页面加载时就能工作，必须通过用户手势调用 `DeviceOrientationEvent.requestPermission()`（脚本已包含启用按钮逻辑）。
- 某些浏览器在未由用户交互触发的情况下会阻止 WebAudio 播放；脚本在首次用户交互后初始化音频上下文。
